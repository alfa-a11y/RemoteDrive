# Remote Drive

A demo website for remote driving a robot. Frontend only.

## Files
- `index.html` - pages and structure
- `styles.css` - dark green design and mobile layout
- `app.js` - navigation, demo login, dashboard, simulated driving

## Run on your computer
Double-click `index.html`. It opens in your browser.

## Important
- The driving controls are a **simulation**. They do not control real hardware.
- Demo accounts are saved in your browser (localStorage). This is **not secure**. Passwords are not saved. Never enter a real password.
- GitHub Pages can only host static files. A real version needs a backend for secure login, a real queue, live video and robot control, plus safety controls.
