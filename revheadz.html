RevHeadz Remote

Control a real phone running the RevHeadz Engine Sounds app from your keyboard. You can start the engine, change gears, press the clutch and use the throttle.

Checking...

Ask the owner for the access code. The remote opens in a new tab.

Controls

Use a laptop or desktop keyboard. Click the remote page once, then:

  • Enter: start or stop the engine
  • W and S: gear up and gear down
  • Space: clutch
  • Arrow Up: throttle (hold it). Arrow Down: throttle down fast

Only one person should drive at a time. If the page does not open, the owner has switched the remote off.
